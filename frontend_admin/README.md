# Bank Sampah Admin — React + Tailwind CSS

Konversi dari dokumen `HTML BANK SAMPAH.docx` menjadi project React/Vite dengan Tailwind CSS.

## Jalankan

1. Install Node.js LTS.
2. Buka terminal di folder project.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka URL Vite yang ditampilkan di terminal.

## Struktur

- `src/components/` reusable UI: Sidebar, PageHeader, StatusBadge, Modal.
- `src/layouts/AdminLayout.jsx` layout admin dengan Sidebar sekali saja.
- `src/pages/` halaman Dashboard, Database Nasabah, Laporan Penjualan, Pengumuman, Live Chat, Form Pengepul, Database Pengepul.
- `src/App.jsx` routing.

## Catatan

Data di halaman masih mock/static untuk mempertahankan tampilan dan alur dari desain sumber. Belum terhubung ke backend/database/IoT.
